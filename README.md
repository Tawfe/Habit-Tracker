# Habit Tracker — with Accountability Partners

Pairs users who check in on each other daily. Build a habit checklist, get
matched with an accountability partner, and receive push notifications when
your partner misses a daily check-in.

Targets **iOS (App Store)**, **Android (Google Play)**, and
**Huawei (AppGallery)**.

---

## Stack

| Layer | Choice |
|---|---|
| Mobile | React Native **bare** 0.86 + TypeScript |
| Navigation | React Navigation (native-stack + bottom-tabs) |
| State | Zustand |
| Backend | **Supabase** (Postgres + Auth + Edge Functions) |
| Push (iOS) | APNs (token / .p8) |
| Push (Android/GMS) | FCM HTTP v1 |
| Push (Huawei) | HMS Push Kit |

### Why three push providers?
Modern Huawei phones ship **without Google Mobile Services**, so FCM does not
deliver to them. The app detects each device's ecosystem at runtime
(`apns` / `fcm` / `hms`) and the backend routes pushes to the matching provider.
See [docs/PUSH-NOTIFICATIONS.md](docs/PUSH-NOTIFICATIONS.md).

## Quick start (local dev)

### 1. Backend (Supabase)
```bash
# Install the Supabase CLI, then:
supabase init                 # if not already
supabase link --project-ref <your-ref>
supabase db push              # applies backend/supabase/migrations
supabase functions deploy register-device
supabase functions deploy join-match-queue
supabase functions deploy missed-checkin-sweep
```
Set function secrets (FCM/APNs/HMS keys, CRON_SECRET) — see
[backend/README.md](backend/README.md).

### 2. App
```bash
cd app
cp .env.example .env          # fill in SUPABASE_URL + SUPABASE_ANON_KEY
npm install
# iOS (needs a Mac):
bundle install && bundle exec pod install --project-directory=ios
npm run ios
# Android:
npm run android
```

## Feature → implementation map

| Feature | Where |
|---|---|
| Habit checklist | `app/src/screens/TodayScreen.tsx`, `features/habits`, `features/checkins` |
| Partner matching | `app/src/screens/PartnerScreen.tsx`, `features/partners`, fn `join-match-queue` |
| Daily check-ins | `checkins` table (unique per user/habit/day), partner-readable via RLS |
| Missed check-in push | fn `missed-checkin-sweep` (scheduled) → `_shared/push/router.ts` |
